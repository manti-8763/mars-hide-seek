# 링크 모델 — `js/physics.js`

링크 하나의 마진을 계산하는 모듈입니다. 메인 스레드와 워커가 함께 씁니다. DOM에도 three.js에도 의존하지 않으므로 Node 같은 다른 JS 환경에서도 그대로 불러올 수 있습니다.

## 1. 좌표와 상수

- **로컬 좌표**: 원점은 격자의 북서 모서리이고, x는 동쪽, y는 남쪽, 단위는 m입니다. 고도도 m이며 기준면은 화성 areoid입니다.
- **셀 위치**: 셀 (i, j)의 중심은 ((j + ½)·res, (i + ½)·res)이고, res는 `meta.res_m`(약 8.10 m)입니다.

| 상수 | 값 | 의미 |
|---|---|---|
| `MARS_R` | 3 389 500 m | 화성 평균 반지름. 곡률 보정에 사용 |
| `K_FACTOR` | 1.0 | 유효 반지름 계수. 화성 대기가 희박해 굴절을 무시 |
| `C0` | 299 792 458 m/s | 광속 |

## 2. 공개 함수

| 함수 | 설명 |
|---|---|
| `makeTerrain(buffer, meta)` | `{z: Float32Array, w, h, res}` 지형 객체를 만듭니다. `z`는 행 우선 배열이고 0행이 북쪽, 자료 없음은 NaN |
| `groundAt(T, x, y)` | 쌍선형 보간 고도. 네 모서리 중 하나라도 NaN이면 가장 가까운 셀 값을 씁니다(그 값도 NaN일 수 있음). 격자 밖 좌표는 가장자리 셀로 고정됩니다 |
| `inside(T, x, y)` | 격자 안이면서 고도가 유효한지 확인합니다. 노드 배치를 허용할지 판단할 때 씁니다 |
| `resolveRadio(P)` | 프리셋·사용자 설정을 계산용 상수 `R`로 바꿉니다(4절) |
| `evalLink(T, R, ax, ay, ha, bx, by, hb, step, out?)` | 링크 마진(dB)을 돌려줍니다. `out` 객체를 넘기면 세부 값을 채웁니다(3절) |
| `linkProfile(T, R, ax, ay, ha, bx, by, hb, step)` | `evalLink`의 세부 값에 그래프용 배열을 더해 돌려줍니다 |
| `J(v)` | 단일 칼날 회절 손실 (ITU-R P.526 근사) |
| `fspl(d, lam)` | 자유공간 경로 손실. 1 m보다 짧은 거리는 1 m로 계산 |
| `widestPath(n, root, linkM)` | 착륙선에서 각 노드까지 병목 마진이 최대인 경로 ([network-and-optimizer.md](network-and-optimizer.md) 1절) |
| `PRESETS`, `PARAM_INFO` | 무선 프리셋과 각 파라미터의 한글 이름·단위 |

`ha`, `hb`는 지면 위 안테나 높이(m)이고 `step`은 단면 표본 간격(m)입니다. 앱은 `step`으로 격자 해상도 `T.res`를 넘깁니다.

## 3. `evalLink` 계산 순서

1. **안테나 절대 높이**: z_A = groundAt(A) + h_A, z_B = groundAt(B) + h_B.
2. **단면 표본** (`fillProfile`): 두 점 사이를 n = ⌈D / step⌉ 구간으로 나누고, 각 표본에 곡률 보정을 더합니다.
   z′ᵢ = zᵢ + dᵢ (D − dᵢ) / (2kR)
   - 양 끝 표본에는 지면 대신 안테나 높이가 들어갑니다.
   - 자료가 없는 표본은 −∞로 둡니다. 그래서 장애물로 계산되지 않습니다.
   - 곡률을 더한 뒤에는 송수신 안테나를 잇는 직선을 그대로 가시선으로 씁니다. 이 보정은 포물선 근사라서 부분 구간에도 그대로 맞습니다. 그래서 회절 모서리를 찾는 하위 구간에서 곡률을 다시 계산하지 않습니다.
3. **가장 나쁜 장애물** (`worstEdge`): 구간 [s, e]의 각 표본에서 가시선 위로 솟은 높이 h, 1차 Fresnel 반지름 r₁ = √(λ d₁ d₂ / L), 여유비 c = −h / r₁를 계산합니다. c가 가장 작은 표본을 고릅니다. 회절 매개변수 v는 −√2·c로 구합니다.
4. **회절 손실 (Deygout, 최대 3개 모서리)**:
   - 주 모서리 p의 v가 −0.78보다 크면 손실은 J(v_p)입니다.
   - 송신점~p 구간과 p~수신점 구간에서 각각 가장 나쁜 모서리를 찾아 J(v)를 더합니다.
   - 이때 p의 높이는 곡률 보정을 더한 z′_p를 씁니다.
5. **경로 손실과 수신 전력**
   - RF: P_r = base − FSPL(D) − L_d
   - 광통신: P_r = base − L_geo(D) − L_atm(D) − L_d
6. **마진**: M = P_r − req.

`D ≤ 2·step`인 아주 짧은 링크는 단면 계산을 건너뛰고 회절 손실을 0으로 둡니다.

`out`에 채워지는 값은 다음과 같습니다.

| 키 | 내용 |
|---|---|
| `D` | 수평 거리 (m) |
| `ga`, `gb`, `za`, `zb` | 양 끝의 지면 고도와 안테나 절대 높이 |
| `Lfs` | 자유공간 손실(RF) 또는 기하 확산 손실(광통신) (dB) |
| `Ld` | 회절 손실 (dB) |
| `Latm` | 먼지 감쇠 (dB). RF에서는 0 |
| `pr`, `req`, `margin` | 수신 전력, 요구 수신 전력, 마진 |
| `clr` | 경로 전체의 최소 Fresnel 여유비 |
| `edges` | 회절 모서리의 단면 인덱스 |

`linkProfile`은 여기에 다음 배열을 더합니다.
- `d`: 거리
- `zRaw`: 지형 고도
- `zFlat`: 곡률 보정을 더한 높이. 양 끝은 지면 높이
- `r1`: 1차 Fresnel 반지름
- `n`: 구간 수

### 성능
- 단면 버퍼(`PD`, `PZ`)는 모듈 수준에서 한 번만 만들어 재사용합니다(최대 32 768 표본). 그래서 반복 계산 중에 메모리 할당이 생기지 않습니다.
- 대신 이 버퍼는 공유 상태라서, 한 스레드 안에서 `evalLink`를 동시에 여러 번 실행할 수 없습니다. JS는 스레드마다 하나씩 순서대로 실행하므로 지금 구조에서는 문제가 되지 않습니다.
- `worstEdge`는 결과를 모듈 변수 `WE_c`, `WE_i`에 담아 돌려줍니다. 객체를 만들지 않기 위해서입니다.

## 4. 무선 설정 (`resolveRadio`)

### RF (`kind: 'rf'`)
- λ = c / f
- base = P_t + G_t + G_r − L_sys
- noise = −174 + NF + 10·log₁₀(R_b) dBm. 290 K 기준의 열잡음입니다.
- req = noise + (E_b/N₀)_req

### 광통신 (`kind: 'optical'`)
- λ = `lambda_nm` × 10⁻⁹
- 먼지 광학두께 파장 변환: τ(λ) = τ₈₈₀ · (λ / 880 nm)^(−α)
- 소산계수: β = τ(λ) / H_dust
- base = P_t − L_opt − L_point
- req = 수신 감도
- 거리별 손실은 `evalLink`에서 계산합니다.
  - 빔 지름: D_spot = D_tx + θ·D
  - 기하 확산 손실: L_geo = 20·log₁₀(D_spot / D_rx). D_spot ≤ D_rx이면 0
  - 먼지 감쇠: L_atm = 4.343·β·D

### 프리셋

| 키 | 이름 | 핵심 값 |
|---|---|---|
| `uhf` | UHF 401 MHz · 음성+텔레메트리 | 30 dBm, 2/2 dBi, 256 kbps, E_b/N₀ 6 dB |
| `sband` | S대역 2.4 GHz · HD 영상 (앱 기본값) | 30 dBm, 3/3 dBi, 10 Mbps, 6 dB |
| `c58` | C대역 5.8 GHz · 고속 데이터 | 30 dBm, 6/6 dBi, 50 Mbps, 8 dB |
| `fso` | 광통신 1550 nm | 23 dBm, 개구 지름 2.5/5 cm, 발산각 1 mrad, 감도 −40 dBm, τ 0.5, α 0.3, H 11 km |

프리셋 값은 실제 장비 사양이 아니라 교육용 가정값입니다. 화면에서 모든 값을 바꿀 수 있습니다.

새 파라미터를 추가할 때는 세 곳을 함께 고칩니다.
1. `PRESETS`의 각 프리셋에 값을 넣습니다.
2. `PARAM_INFO`에 한글 이름과 단위를 넣습니다. 사이드바 입력 칸은 이 정보로 자동 생성됩니다.
3. `resolveRadio`에서 그 값을 계산에 반영합니다.

## 5. 모델이 다루지 않는 것

- 지면 반사와 다중경로
- 안테나 지향성. 이득은 상수로만 반영
- 사람 몸이나 구조물에 의한 차폐
- 전리층 효과. UHF 이상 주파수에서는 무시할 수 있음
- RF의 먼지 감쇠. 수 km 지표 경로에서는 무시할 만큼 작음
- Deygout 방식의 경험적 보정항. 그래서 모서리가 여러 개인 경로의 손실은 다소 크게 나옵니다
- 8 m로 평균한 지형에서 사라진 작은 장애물. 그래서 가시선 판정이 실제보다 낙관적입니다

## 6. 검산 값

같은 모델을 numpy로 따로 구현해 비교했을 때 일치한 S대역 시험 링크입니다. 코드를 고친 뒤 회귀 확인용으로 쓸 수 있습니다.

```js
const R = __sim.PH.resolveRadio(__sim.PH.PRESETS.sband), o = {};
__sim.PH.evalLink(__sim.S.T, R, 4000, 300, 4, 5200, 1900, 2, __sim.S.T.res, o);
// o.D = 2000.00, o.Lfs = 106.07, o.Ld = 74.00, o.clr = −8.99, o.margin = −51.07
```
